# RetroN64-HTML

Welcome to the github page of RetroN64 Html or RetroN64 its an emulator of the n64 for web browsers
that its optimized for bad computers

# SETUP
1-First install the file Called RetroN64
2-Go to cloudflare and Login or Sign up then go to Workers & Pages Then Start with hello world and then Deploy then go to edit
Code and paste the js file once you have done it hit deploy copy the worker page 
3-go to the emulator and paste the worker page
4-put some roms in it and play

you can play with some controlers with bluetooth and usb
